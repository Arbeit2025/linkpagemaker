# リンク集ページ・メーカー（linkpagemaker）

プロフィール名・一言・リンク一覧を入れるだけで、リンク集ページの単一HTMLを生成するメーカーです。着想元は Python-arr1215 の Portfolio（リンク集ページの形）です。

## 機能

- **リンク集セットの作成**：プロフィール名、一言（任意）、リンク複数件（タイトル＋URL）を入力してセットとして保存します。
- **一覧・表示・削除**：保存したセットはトップページに一覧表示され、表示ページで内容確認と削除ができます。
- **プレビューとダウンロード**：セットの表示ページでは、生成されるリンク集ページをその場でプレビューでき、「HTMLをダウンロード」ボタンで単一の `.html` ファイルとして保存できます。
- **自己完結HTML**：生成されるHTMLは外部CSS/JSを一切使わず、インラインスタイルだけで完結します。ダウンロードしたファイルをそのままブラウザで開いたり、任意の場所に置いたりできます。

## 安全面の仕様

- すべてのユーザー入力（名前・一言・タイトル・URL）は、生成HTMLに埋め込む際にHTMLエスケープします。
- リンクのURLは **http / https のみ許可**します。`javascript:` などの危険なスキームは登録時に拒否します。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

DB のパスは環境変数 `LINKPAGEMAKER_DB` で変更できます。

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- ログイン機能はありません。誰でもセットの作成・削除ができます。
- 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。大事なリンク集は、生成したHTMLをダウンロードして手元に残してください。
- リンクは最大50件までです。
